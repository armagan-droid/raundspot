# GymSpot Solo *(çalışma adı)*

Muay Thai öğrencileri için bireysel iOS uygulaması: telefonun kamerasıyla çalışan **sanal rakip**. Uygulama rastgele sesli saldırı işareti verir ("jab!", "kroşe!"), kullanıcı doğru eskivle (slip, duck, bob & weave, lean back) tepki verir; kamera hareketin doğruluğunu ve tepki süresini ölçer. Teknik modu, refleks modu, kuvvet ve kondisyon, HealthKit. Her şey telefonda çalışır; sunucu yok.

Proje **spec-driven** geliştirilir: önce `specs/` okunur. Claude Code için kurallar `CLAUDE.md` içindedir.

Başlangıç: `specs/00-vision.md` → `specs/14-roadmap.md` (görev sırası).

Hareket şablonu formatı ve kural motoru, GymSpot salon ürününden (B2B PWA) commit `c2fe3fd` anında çatallanmıştır; o andaki salon spec'leri `docs/reference/b2b/` altındadır.
